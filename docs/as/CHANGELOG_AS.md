# CHANGELOG_AS

`SPEC_ISSUES.md` item). Each entry: date, SI number, what changed (files, fields, rules), why,
and which protected tests were updated. A change here is the only legitimate way a protected
file changes after `as-kit-baseline`. After editing the protected files, the human (never the agent)
refreshes the hashes: `AS_MAINTAINER=1 python tools/as/protect.py --write-manifest`.
